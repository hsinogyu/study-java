# HTTP 서버 만들기

## HTTP 서버 1 - 시작

### 목표
- 웹 브라우저에서 우리 서버에 접속하면 다음과 같은 HTML을 응답하는 것
```html
<h1>Hello World</h1>
```
- 참고
  - 원래 다양한 태그를 사용해야하지만 문제를 단순하게 만들기 위해 최소한의 태그만 사용함

### 코드
```java
public class HttpServerV1 {

    private final int port;

    public HttpServerV1(int port) {
        this.port = port;
    }

    public void start() throws IOException {
        ServerSocket serverSocket = new ServerSocket(port);
        log("서버 시작 port: " + port);

        while (true) {
            Socket socket = serverSocket.accept();
            process(socket);
        }
    }

    private void process(Socket socket) throws IOException {
        try (
                socket;
                BufferedReader reader = new BufferedReader(new InputStreamReader(socket.getInputStream(), StandardCharsets.UTF_8));
                PrintWriter writer = new PrintWriter(socket.getOutputStream(), false, StandardCharsets.UTF_8)
        ) {
            String requestString = requestToString(reader);
            if (requestString.contains("/favicon.ico")) {
                log("favicon 요청");
                return;
            }

            log("HTTP 요청 정보 출력");
            System.out.println(requestString);

            log("HTTP 응답 생성중...");
            sleep(5000); // 서버 처리 시간
            responseToClient(writer);
            log("HTTP 응답 전달 완료");
        }
    }

    private String requestToString(BufferedReader reader) throws IOException {
        StringBuilder sb = new StringBuilder();
        String line;
        while ((line = reader.readLine()) != null) {
            if (line.isEmpty()) {
                break;
            }
            sb.append(line).append("\n");
        }
        return sb.toString();
    }

    private void responseToClient(PrintWriter writer) {
        // 웹 브라우저에 전달하는 내용
        String body = "<h1>Hello World</h1>";
        int length = body.getBytes(StandardCharsets.UTF_8).length;

        StringBuilder sb = new StringBuilder();
        sb.append("HTTP/1.1 200 OK\r\n");
        sb.append("Content-Type: text/html\r\n");
        sb.append("Content-Length: ").append(length).append("\r\n");
        sb.append("\r\n");
        sb.append(body);

        log("HTTP 응답 정보 출력");
        System.out.println(sb);

        writer.println(sb);
        writer.flush(); // 이때 실제 전송됨 - 위에서 autoflush = false로 설정함
    }

    private void sleep(int millis) {
        try {
            Thread.sleep(millis); //
        } catch (InterruptedException e) {
            throw new RuntimeException(e);
        }
    }
}
```

```java
public class ServerMain {

    private static final int PORT = 12345;

    public static void main(String[] args) throws IOException {
        HttpServerV1 server = new HttpServerV1(PORT);
        server.start();
    }
}
```

### AutoFlush
- new PrintWriter(socket.getOutputStream(), false, UTF_8)
  - PrintWriter의 두 번째 인자는 autoFlush 여부
  - 이 값을 true로 설정하면 println()으로 출력할 때마다 자동으로 플러시 됨
    - 첫 내용을 빠르게 전송할 수 있지만, 네트워크 전송이 자주 발생함
  - 이 값을 false로 설정하면 flush()를 직접 호출해주어야 데이터를 전송함
    - 데이터를 모아서 전송하므로 네트워크 전송 횟수를 효과적으로 줄일 수 있음
    - 한 패킷에 많은 양의 데이터를 담아서 전송할 수 있음
  - 여기서 false로 설정했으므로 마지막에 꼭 writer.flush()를 호출해야함

### requestToString()
- HTTP 요청을 읽어서 String을 반환함
- HTTP 요청의 시작 라인, 헤더까지 읽음
  - line.isEmpty()이면 HTTP 메시지 헤더의 마지막으로 인식하고 메시지 읽기를 종료함
  - HTTP 메시지 헤더의 끝은 빈 라인으로 구분할 수 있음. 빈 라인 이후에는 메시지 바디가 나옴
  - 참고로 여기서는 메시지 바디를 전달하지 않으므로 메시지 바디의 정보는 읽지 않음

### GET /favicon.ico
- 웹 브라우저 아이콘을 요청
- 여기서는 무시

### sleep(5000)
- 서버 처리 시간을 가정

### responseToClient()
- HTTP 응답 메시지를 생성해서 클라이언트에 전달함
- 시작라인, 헤더, HTTP 메시지 바디를 전달함
- 주의
  - HTTP 공식 스펙에서는 다음 라인은 `\r\n`으로 표현함
  - 참고로 `\n`만 사용해도 대부분의 웹 브라우저는 문제없이 작동함
- 마지막에 writer.flush()를 호출해서 데이터를 전송함

### 현재 한계
- **단일 스레드의 한계로 동시에 요청을 받으면 순차적으로 처리를 진행함**
- 1번째 요청: 5초
- 2번째 요청: 10초(1번째 요청 + 5초)

## HTTP 서버 2 - 동시 요청

### 코드
```java
public class HttpServerV2 {

    private final static ExecutorService es = Executors.newFixedThreadPool(10);
    private final int port;

    public HttpServerV2(int port) {
        this.port = port;
    }

    public void start() throws Exception {
        ServerSocket serverSocket = new ServerSocket(port);
        log("서버 시작 port: " + port);

        while (true) {
            Socket socket = serverSocket.accept();
            es.submit(new HttpRequestHandlerV2(socket));
        }
    }
}
```

```java
public class HttpRequestHandlerV2 implements Runnable {

    private final Socket socket;

    public HttpRequestHandlerV2(Socket socket) {
        this.socket = socket;
    }

    @Override
    public void run() {
        try {
            process();
        } catch (Exception e) {
            log(e);
        }
    }

    private void process() throws IOException {
        try (
                socket;
                BufferedReader reader = new BufferedReader(new InputStreamReader(socket.getInputStream(), StandardCharsets.UTF_8));
                PrintWriter writer = new PrintWriter(socket.getOutputStream(), false, StandardCharsets.UTF_8)
        ) {
            String requestString = requestToString(reader);
            if (requestString.contains("/favicon.ico")) {
                log("favicon 요청");
                return;
            }

            log("HTTP 요청 정보 출력");
            System.out.println(requestString);

            log("HTTP 응답 생성중...");
            sleep(5000); // 서버 처리 시간
            responseToClient(writer);
            log("HTTP 응답 전달 완료");
        }
    }

    private String requestToString(BufferedReader reader) throws IOException {
        StringBuilder sb = new StringBuilder();
        String line;
        while ((line = reader.readLine()) != null) {
            if (line.isEmpty()) {
                break;
            }
            sb.append(line).append("\n");
        }
        return sb.toString();
    }

    private void responseToClient(PrintWriter writer) {
        // 웹 브라우저에 전달하는 내용
        String body = "<h1>Hello World</h1>";
        int length = body.getBytes(StandardCharsets.UTF_8).length;

        StringBuilder sb = new StringBuilder();
        sb.append("HTTP/1.1 200 OK\r\n");
        sb.append("Content-Type: text/html\r\n");
        sb.append("Content-Length: ").append(length).append("\r\n");
        sb.append("\r\n");
        sb.append(body);

        log("HTTP 응답 정보 출력");
        System.out.println(sb);

        writer.println(sb);
        writer.flush(); // 이때 실제 전송됨 - 위에서 autoflush = false로 설정함
    }

    private void sleep(int millis) {
        try {
            Thread.sleep(millis); //
        } catch (InterruptedException e) {
            throw new RuntimeException(e);
        }
    }
}
```
- ExecutorService: 스레드 풀을 사용함
  - 여기서는 newFixedThreadPool(10)을 사용해서 최대 동시에 10개의 스레드를 사용할 수 있도록 함
  - 결과적으로 10개의 요청을 동시에 처리할 수 있음
- 실무에서는 상황에 따라 다르지만 보통 수백 개 정도의 스레드를 사용함
- es.submit(new HttpRequestHandlerV2(socket)): 스레드 풀에 HttpRequestHandlerV2 작업을 요청함
- 스레드 풀에 있는 스레드가 HttpRequestHandlerV2의 run()을 수행함

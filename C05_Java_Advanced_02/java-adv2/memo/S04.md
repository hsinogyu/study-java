# I/O 기본 2

## 문자 다루기 1 - 시작

### bytes[] writeBytes = writeString.getBytes(UTF_8)
- String을 byte로 변환할 때는 String.getBytes(Charset)을 사용
- 이때 문자를 byte 숫자로 변경해야하기 때문에 반드시 문자 집합(인코딩 셋)을 지정해야 함
- ABC를 인코딩하면 65, 66, 67이 됨

### String readString = new String(readBytes, UTF_8)
- 반대의 경우도 비슷함
- String 객체를 생성할 때, 읽어들인 byte[]와 디코딩할 문자 집합을 전달하면 됨
- 그러면 byte[]를 String 문자로 다시 복원할 수 있음

### 핵심
- 스트림은 byte만 사용할 수 있으므로 String과 같은 문자는 직접 전달할 수 없다는 점
- 과정
  - String -> byte[]
  - byte[] -> String

## 문자 다루기 2 - 스트림을 문자로

### OutputStreamWriter / InputStreamWriter
- OutputStreamWriter: 스트림에 byte 대신 문자를 지정할 수 있게 지원함
- InputStreamReader: 스트림에 byte 대신에 문자를 읽을 수 있게 지원함

### 예제
```java
public class ReaderWriterMainV2 {

    public static void main(String[] args) throws IOException {
        String writeString = "ABC";
        System.out.println("write String: " + writeString);

        // 파일에 쓰기
        FileOutputStream fos = new FileOutputStream(TextConst.FILE_NAME);
        OutputStreamWriter osw = new OutputStreamWriter(fos, StandardCharsets.UTF_8);

        osw.write(writeString);
        osw.close();

        // 파일에서 읽기
        FileInputStream fis = new FileInputStream(TextConst.FILE_NAME);
        InputStreamReader isr = new InputStreamReader(fis, StandardCharsets.UTF_8);

        StringBuilder sb = new StringBuilder();
        int ch;
        while ((ch = isr.read()) != -1) {
            sb.append((char) ch);
        }
        isr.close();

        System.out.println("read String: " + sb);
    }
}
```
- OutputStreamWriter
  - OutputStreamWriter는 문자를 입력받고, 받은 문자를 인코딩해서 byte[]로 변환함
  - OutputStreamWriter는 변환한 byte[]를 전달할 OutputStream과 인코딩 문자 집합에 대한 정보가 필요함
    - new OutputStreamWriter(fos, UTF_8);
  - osw.write(writeString)을 보면 String 문자를 직접 전달하는 것을 확인할 수 있음

- InputStreamReader
  - 데이터를 읽을 때는 int ch = read()를 제공하는데, 여기서는 문자 하나인 char 형으로 데이터를 받게 됨
  - 그런데 실제 반환 타입은 int형이므로 char 형으로 캐스팅해서 사용하면 됨
  - 자바의 char 형은 파일의 끝인 -1을 표현할 수 없으므로 int를 반환함
  - FileINputStream에서 byte[]를 읽은 것을 확인할 수 있음
    - new InputStreamReader(fis, UTF_8)

### 참고
- char: UTF_16으로 되어있음 -> UTF_8로 지정하고 읽으면 UTF_8로 읽어서 내부적으로 다시 UTF_16으로 변환해서 들고 있음

## 문자 다루기 3 - Reader, Writer

### byte를 다루는 크래스
- OutputStream
  - FileOutputStream
  - ByteArrayOutputStream
  - BufferedOutputStream

- InputStream
  - FileInputStream
  - ByteArrayInputStream
  - BufferedInputStream

### 문자를 다루는 클래스
- Writer (write(String) / write(char[]))
  - OutputStreamWriter
    - FileWriter
  - BufferedWriter

- Reader (read(): int(char) / read(char[]))
  - InputStreamReader
    - FileReader
  - BufferedReader

### 차이
- byte를 다루는 크래스는 OutputStream, InputStream의 자식
  - 부모 클래스의 기본 기능도 byte 단위를 다룸
  - 클래스 이름 마지막에 보통 OutputStream / InputStream이 붙어있음

- 문자를 다루는 클래스는 Writer, Reader의 자식
  - 부모 클래스의 기본 기능은 String, char 같은 문자를 다룸
  - 클래스 이름 마지막에 보통 Writer, Reader가 붙어있음

### 매우 중요
- 모든 데이터는 byte 단위(숫자)로 저장됨
- 따라서 Writer가 아무리 문자를 다룬다고 해도 문자를 바로 전달할 수는 없음
- 내부적으로 지정된 문자 집합을 사용해서 문자를 byte로 인코딩해서 저장함

### FileWriter / FileReader
```java
public class ReaderWriterMainV3 {

    public static void main(String[] args) throws IOException {
        String writeString = "abc";
        System.out.println("write String: " + writeString);

        // 파일에 쓰기
        FileWriter fw = new FileWriter(TextConst.FILE_NAME, StandardCharsets.UTF_8);

        fw.write(writeString);
        fw.close();

        // 파일에서 읽기
        FileReader fr = new FileReader(TextConst.FILE_NAME, StandardCharsets.UTF_8);

        StringBuilder sb = new StringBuilder();
        int ch;
        while ((ch = fr.read()) != -1) {
            sb.append((char) ch);
        }
        fr.close();

        System.out.println("read String: " + sb);
    }
}
```
- FileWriter를 들어가서 보면 super(FileOutputStream(fileName), Charset)을 호출함

### fw.write(writeString)
- 이 메서드를 사용하면 문자를 파일에 직접 쓸 수 있음
- 문자를 쓰면 인코딩 셋을 사용해서 바이트로 변경하고 FileOutputStream을 사용해서 파일에 저장함

### new FileReader(FILE_NAME, UTF_8)
- 내부에서 FileOutputStream을 생성해서 사용함
- 데이터를 byte 단위로 읽어들임
- 문자 집합을 사용해서 byte[]를 char로 디코딩함

### 참고
- **문자 집합을 생략하면 시스템 기본 문잡 집합을 사용함**

## 문자 다루기 4 - BufferedReader

### 특징
- 한 줄 단위로 문자를 읽음

### 예제
```java
public class ReaderWriterMainV4 {

    private static final int BUFFER_SIZE = 8192;

    public static void main(String[] args) throws IOException {
        String writeString = "abc\n가나다";
        System.out.println("== Write String ==");
        System.out.println(writeString);

        // 파일에 쓰기
        BufferedWriter bw = new BufferedWriter(new FileWriter(TextConst.FILE_NAME, StandardCharsets.UTF_8), BUFFER_SIZE);

        bw.write(writeString);
        bw.close();

        // 파일에서 읽기
        BufferedReader br = new BufferedReader(new FileReader(TextConst.FILE_NAME, StandardCharsets.UTF_8), BUFFER_SIZE);

        StringBuilder sb = new StringBuilder();
        String line;
        int cnt = 0;
        while ((line = br.readLine()) != null) {
            sb.append(line).append("\n");
            cnt++;
        }
        br.close();

        System.out.println("== Read String ==");
        System.out.println(sb);
        System.out.println("cnt: " + cnt); // 2번 읽음(2줄)
    }
}
```
- readLine() 한 줄 씩 읽고 String을 반환함
- 더 이상 읽을 것이 없을 때, null을 반환함

## 기타 스트림

### PrintStream
```java
public class PrintStreamEtcMain {

  public static void main(String[] args) throws FileNotFoundException {
    FileOutputStream fos = new FileOutputStream("temp/print.txt");
    PrintStream ps = new PrintStream(fos);

    ps.println("hello java!");
    ps.println(10);
    ps.println(true);
    ps.printf("hello %s", "world");
    ps.close();

    PrintStream printStream = System.out;
    printStream.println("Hello World");
    printStream.close();
  }
}
```
- 이제 PrintStream으로 나가는 출력은 파일에 저장됨
- 이 기능을 사용하면 마치 콘솔에 출력하는 것처럼 파일이나 다른 스트림에 문자를 출력할 수 있음
- 주의: System.out으로 받은 PrintStream을 닫으면 이후 System.out을 할 수 없음

### DataOutputStream
- 자바의 String, int, double, boolean 같은 데이터 형을 편리하게 다룰 수 있음
```java
public class DataStreamEtcMain {

    public static void main(String[] args) throws IOException {
        FileOutputStream fos = new FileOutputStream("temp/data.dat");
        DataOutputStream dos = new DataOutputStream(fos);

        dos.writeUTF("회원 A"); // UTF-8로 저장함 (3바이트)
        dos.writeInt(20); // 4바이트로 저장함
        dos.writeDouble(10.5); // 8바이트로 저장함
        dos.close();

        FileInputStream fis = new FileInputStream("temp/data.dat");
        DataInputStream dis = new DataInputStream(fis);

        // 반드시 저장한 순서대로 읽어야 함
        String n1 = dis.readUTF();
        int n2 = dis.readInt();
        double n3 = dis.readDouble();
        dis.close();

        System.out.println("n1 = " + n1);
        System.out.println("n2 = " + n2);
        System.out.println("n3 = " + n3);
    }
}
```
- 주의사항: 반드시 저장한 순서로 읽어야 함
  - 또한 그냥 순수 해당 자료형의 바이트로 저장하기 때문에 파일에서는 깨짐

## 정리

### 정리
- 기본(기반, 메인) 스트림
  - File, 메모리, 콘솔 등에 직접 접근하는 스트림
  - 단독으로 사용할 수 있음
  - FileInputStream, FileOutputStream, FileReader, FileWriter, ByteArrayInputStream, ByteArrayOutputStream

- 보조 스트림
  - 기본 스트림을 도와주는 스트림
  - 단독으로 사용할 수 없음, 반드시 대상 스트림이 있어야함
  - BufferedInputStream, BufferedOutputStream, InputStreamReader, OutputStreamWriter, DataOutputString, DataInputStream, PrintStream
